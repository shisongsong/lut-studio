LUT 装在哪里：每个软件的准确路径

同一支 .cube，在不同软件里的入口完全不同，而且"创意 LUT"和"LOG 转换 LUT"要放的位置也不一样。这一页把常用软件的菜单路径、文件夹位置和容易踩的坑一次列清；装之前想先看看效果，直接在浏览器里套一遍最快。

更新 2026-11-256 分钟

先分清两类 LUT，放错位置是绝大多数"套上之后不对"的原因：

  • LOG 转换 LUT（厂商发布、名字里常带 F-Log / V-Log / S-Log / N-Log）：它的作用是把 LOG 编码的画面转换到 Rec.709，应该放在输入侧——Premiere 的 Input LUT、Resolve 的节点前段、FCP 的输入 LUT 槽。喂给它普通 sRGB 照片或已转换的画面，结果会发灰或过曝。
  • 创意 LUT（风格 look）：放在显示编码的画面上，应该挂在调色链的后段——Premiere 的 Creative → Look、Resolve 的后段节点、PS/Affinity 的调整图层。本站的 64 款 look 属于这一类，为显示编码的照片设计。

各软件的位置

各软件的 .cube 安装位置（2026-11 核对）
软件位置
Photoshop图层 → 新建调整图层 → 颜色查找（Color Lookup）→ 载入 3D LUT，选中 .cube 文件。
调整图层不破坏原图；强度用图层不透明度控制。也可以把 LUT 打包成 Camera Raw 配置文件（见 Lightroom 一节）。
Premiere ProLumetri Color → Creative → Look → Browse，选 .cube。
LOG 素材的转换 LUT 应该放在 Basic Correction → Input LUT，而不是 Creative 的 Look——前者是"把 LOG 变成 Rec.709"，后者是创意调色。强度在 Intensity 滑轨上。
DaVinci ResolveProject Settings → Color Management → Lookup Tables → Open LUT Folder，把 .cube 放进对应目录并 Update Lists；或直接在 Color 页的 LUT 浏览面板里右键 Refresh。
默认目录：macOS /Library/Application Support/Blackmagic Design/DaVinci Resolve/LUT；Windows C:\ProgramData\Blackmagic Design\DaVinci Resolve\Support\LUT。Linux 通常在 /opt/resolve/LUT（以本机安装为准）。
Final Cut Pro把 .cube 放进 ~/Library/Application Support/ProApps/Color Profiles/LUTs（没有 Color Profiles/LUTs 就自己建），然后给片段加 Effects → Color → Custom LUT，在 LUT 菜单里选它。
FCP 只在启动时读取该目录，放完文件要重启一次。
After EffectsEffect → Color Correction → Apply Color LUT，在效果控件里指向 .cube；或者用 Lumetri Color 的 Creative → Look。
调整层上挂 LUT、下面放素材，强度和开关都集中在调整层上。
Lightroom Classic它不能直接打开 .cube。路是：Photoshop → Filter → Camera Raw Filter → Presets 面板里 Option/Alt 点 ⋯ → Create Profile，勾 Color Lookup Table 并载入 .cube，存成 .xmp 配置；然后重启 Lightroom，在 Develop → Basic → 配置文件浏览器里用它。
需要 Lightroom Classic 7.3（2018 年 4 月）或更新；配置文件有 0–200 的 Amount 滑轨，强度从这里调。
Affinity Photo图层 → 新建调整图层 → LUT（或 Adjustments 面板里的 LUT），然后在对话框里 Load LUT 选 .cube。
不破坏原图，强度用图层不透明度。

一个通用流程

  1. 先预览：把照片拖进浏览器里的编辑器，在胶片条上套一遍看方向对不对——本机渲染，不上传。
  2. 再下载：单支 .cube 在各自的 look 页下（比如 柯达 Portra 400），或者一次拿全部 64 款。
  3. 按上表装进软件：装完在软件里做一次身份验证——套上 LUT 再关掉，画面应当完全回到原样。回不去就说明前置的色彩管理或输入曲线不对。
  4. 调强度：多数软件都有 Intensity / Amount / 不透明度，先看 100% 再决定降多少。LUT 是色彩映射，不能恢复已经过曝的白。

三个常见坑

  • Resolve 找不到 LUT：文件放进目录后要 Update Lists / Refresh，Resolve 不会自动扫描新文件。
  • Final Cut Pro 装完没出现：它只在启动时读 LUT 目录，放完要重启。
  • Lightroom Classic 说"不支持 .cube"：它确实不能直接打开，但可以把 LUT 包成配置文件（上表最后一行），之后在配置文件浏览器里用。
