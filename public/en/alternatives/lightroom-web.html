Is there a free browser alternative to Lightroom?

Half of one. A browser can develop a single RAW, grade it and export a JPEG for free; the other half of Lightroom — catalogue, batch and cloud library — has no free browser replacement, and this tool does not pretend otherwise.

Updated 2026-11-207 min read

Is there a free browser version of Lightroom?

Yes for half the job, no for the other half. Lightroom is two things at once: a RAW developer and a workflow built around a catalogue and a cloud library. A browser can do the first half for free — open one RAW, develop it like a darkroom, apply a LUT, export a JPEG — with no install, no account and no upload. The second half, a library with batch and cross-device sync, has no free browser replacement today, and this browser editor does not attempt it.

So before picking a tool, work out which half your job needs.

What this browser darkroom actually does

It is a single-frame darkroom. Open a RAW in the browser and flashraw decodes it in a Web Worker; the 16-bit scene-linear frame is developed on the GPU, using darktable's sigmoid display transform. A synthetic linear EV ramp is pixel-compared against darktable 5.6.2 CLI output with an observed maximum linear error of 0.0014772; this checks the curve, not a full camera RAW pipeline or Lightroom Auto equivalence.

  • RAW decoding: NEF / NRW (including HE and HE* compression), CR2, CR3, ARW, SRF, SR2, DNG, RAF, ORF, RW2, PEF, SRW, 3FR, ERF, KDC, MOS, IIQ, X3F; if a file cannot be unpacked, the camera JPEG embedded in it is used instead.
  • Development: white balance and exposure operate in linear light; every tone slider places its band from this photo's measured EV percentiles (highlights tighten the measured top, shadows open the measured bottom while locking the black point, whites/blacks move only their measured ends, contrast pivots on the measured median) and the curve is built as a monotone LUT; a RAW also opens with scene-derived auto exposure, and the exposure slider is an offset from it.
  • LUTs: 64 built-in looks with adjustable strength, a second slot for stacking, a merge into one .cube, and local .cube import. The full list is in the look catalogue.
  • Export: JPEG at 50 / 75 / 100 % of the source long edge; 100 % renders the in-memory full-resolution frame in tiles.
  • Privacy: no account, no upload, no analytics; the only network requests are app assets and a /api/geo country lookup used to pick the interface language.

What it explicitly does not do

This section exists to save you time. If you need any of the following, stop looking in this direction and open a desktop application.

  • No library or catalogue: one photo at a time; close the tab and there is no last edit, no ratings, keywords or collections.
  • No batch: you cannot apply one set of adjustments to 200 RAW files, and there is no queue or sync.
  • No cloud sync: imported LUTs and interface preferences live in the browser's IndexedDB / localStorage, so another device or browser starts empty.
  • No AI masks: no subject, sky or portrait masking.
  • No .xmp presets: Lightroom presets do not import; .cube files do.
  • Prerequisites: a WebGL2 browser; preview capped at 4096 px on the long edge (export is not capped); the first RAW open downloads about 3.4 MB of decoder, cached afterwards.

Pick by the job you have

I just need to develop one RAW on a borrowed laptop

The browser is the shortest path here: nothing to install, no sign-in, and no copying the card onto someone else's machine to install a trial. Open the editor, drop the file in, develop it, apply a look, export the JPEG. The trade-off is its boundaries: the first RAW open needs a network connection to fetch the decoder, and what you leave with is a JPEG plus a merged .cube if you made one — not an .xmp that another app can keep editing from.

I have 200 RAW files to batch

This tool is out of its depth here: no batch, no queue. This is desktop territory — Lightroom's catalogue and cloud sync are organised around groups of photos, and darktable and RawTherapee are full desktop RAW pipelines. If batch is a one-off, a free desktop tool covers it; if batch is your normal week, that is what a catalogue-based product is for.

I need to use Fujifilm or Kodak-style look LUTs

Among the 64 built-in looks are Kodak, Fujifilm, Ricoh, Panasonic, Leica and Hasselblad-inspired recipes, with adjustable strength, a second slot for stacking and a merge into one .cube. One honest caveat: these are original recipes written to match the colour response of those styles, not vendor LUT data — close in look, not a byte-for-byte reproduction. Vendor LUTs do import, but they are built for log input: set the input profile to F-Log, F-Log2 or V-Log (a LUT whose name carries the tag is detected automatically) and the app re-encodes the frame with the published transfer function before the LUT runs. Gamut is still treated as sRGB, so the result is close but not byte-exact. Details are in the RAW-in-browser guide and the look catalogue.

I do not want my photos uploaded

Decoding, development and rendering all happen on this machine, and there is no upload endpoint. When judging another tool, ask where the processing happens: a browser app that renders locally or a desktop app that never touches a server is not the same category as a workflow built around a cloud library. If a photo must not pass through any third-party server, that constraint matters more than the feature list.

Three follow-up questions

Is there a free browser alternative to Lightroom?

Yes, for half the job: a browser can open one RAW, develop it, apply a LUT and export a JPEG for free. There is no free browser replacement for a catalogue, batch processing or cloud sync.

Can this tool replace Lightroom’s library and batch processing?

No. It is a single-frame editor: no catalogue, ratings, keywords, batch queue or sync.

Can I import Lightroom presets?

Not .xmp presets. You can import .cube LUTs, or rebuild the grade with the built-in looks and the develop panel.

The short answer

If you need a library, batch or cross-device sync, there is no free browser replacement — use desktop software. If you need to develop one RAW, grade it and leave with a JPEG on whatever machine you are sitting at, a free browser tool is already enough, and it skips the install entirely.
