Each file is a standard 3D LUT with LUT_3D_SIZE 33, DOMAIN_MIN 0 0 0 and DOMAIN_MAX 1 1 1, expecting sRGB / Rec.709 input. 33³ means 35,937 nodes, which is exact for the recipes in this repository: 17³ has a mean error of 0.23 levels (max 20.8), 21³ a mean of 0.18 (max 11.6), 33³ zero. The measurements are here.

Installing it elsewhere

Where the four common apps keep their LUT import
AppWhere
DaVinci ResolveProject Settings → Color Management → Lookup Tables, or add the folder in the LUTs panel on the Color page
Premiere ProLumetri Color → Creative → Look → Browse
PhotoshopLayer → New Adjustment Layer → Color Lookup → Load 3D LUT
Final Cut ProEffects → Color → Custom LUT → Choose LUT
Lightroom ClassicCannot open a .cube directly. Package it as a profile in Adobe Camera Raw (Presets ⋯ → Create Profile → tick Color Lookup Table) and use it from the Profile Browser — or just preview it in the browser editor.

Judge a look at 100 % strength first — that is what the archive contains. For a softer result, lower the strength where the app supports it, or preview it with the strength rail in the editor; two looks can also be merged into one new .cube.

Licence and provenance

These are recipes written for this project (scripts/looks.mjs) and baked into LUTs, not film scans and not vendor-published data. Code and output are MIT licensed; commercial use is fine and no attribution is required. The names point at a style — what the file actually delivers is a reproducible grading curve.

Vendor LUTs (Panasonic, Fujifilm, Canon, Nikon, Sony) are only licensed for personal local use and cannot be redistributed, so they are not in this zip. Get those from the official download sources and import the file into the editor yourself.

Honest limits

  • The editor processes one photo at a time: no batch, no catalogue, no cloud sync.
  • A LUT is a colour mapping and cannot recover clipped white; RAW highlight recovery happens before the LUT.
  • 33³ was chosen for this recipe set: 65³ doubles the size for no visible gain.
  • The archive contains no photos and needs no network connection to use.

Try before you download
