Where a LUT actually goes, app by app

The same .cube lives in a different place in every app — and a creative look goes somewhere different from a LOG conversion LUT. This page lists the menu paths, the folders and the usual traps; if you want to see the result first, preview it in the browser instead of installing anything.

Updated 2026-11-256 min read

Two kinds of LUT, and putting one in the other's slot is the cause of most "it looks wrong after installing":

  • LOG conversion LUTs (published by camera makers, usually named F-Log / V-Log / S-Log / N-Log): they convert LOG-encoded footage to Rec.709 and belong on the input side — Premiere's Input LUT, an early node in Resolve, the input LUT slot in FCP. Feed them an ordinary sRGB photo or already-converted footage and the result goes flat or blown out.
  • Creative LUTs (looks): they work on display-encoded images and belong late in the chain — Premiere's Creative → Look, a late Resolve node, an adjustment layer in Photoshop or Affinity. The 64 looks on this site are in this group and are authored for display-encoded photos.

Where each app expects it

Where each app expects a .cube (checked Nov 2026)
AppWhere
PhotoshopLayer → New Adjustment Layer → Color Lookup → Load 3D LUT, then pick the .cube file.
The adjustment layer is non-destructive; use the layer opacity for strength. You can also package the LUT as a Camera Raw profile (see the Lightroom row).
Premiere ProLumetri Color → Creative → Look → Browse, then pick the .cube.
A LOG-conversion LUT belongs in Basic Correction → Input LUT, not in Creative → Look: the first turns LOG into Rec.709, the second is a creative grade. Strength lives on the Intensity slider.
DaVinci ResolveProject Settings → Color Management → Lookup Tables → Open LUT Folder, drop the .cube in and press Update Lists; or right-click the LUT browser on the Color page and Refresh.
Default folders: macOS /Library/Application Support/Blackmagic Design/DaVinci Resolve/LUT; Windows C:\ProgramData\Blackmagic Design\DaVinci Resolve\Support\LUT; Linux usually /opt/resolve/LUT (check your install).
Final Cut ProPut the .cube into ~/Library/Application Support/ProApps/Color Profiles/LUTs (create the folder if missing), then add Effects → Color → Custom LUT to a clip and pick it from the LUT menu.
FCP reads that folder at launch, so restart it once after adding files.
After EffectsEffect → Color Correction → Apply Color LUT and point the effect controls at the .cube; or use Lumetri Color → Creative → Look.
Put the LUT on an adjustment layer above the footage so strength and on/off live in one place.
Lightroom ClassicIt cannot open a .cube directly. The route: Photoshop → Filter → Camera Raw Filter → hold Option/Alt and click ⋯ in the Presets panel → Create Profile, tick Color Lookup Table and load the .cube; that writes an .xmp profile. Restart Lightroom, then use it from Develop → Basic → Profile Browser.
Requires Lightroom Classic 7.3 (April 2018) or newer. Profiles expose a 0–200 Amount slider for strength.
Affinity PhotoLayer → New Adjustment Layer → LUT (or the LUT adjustment in the Adjustments panel), then Load LUT and pick the .cube.
Non-destructive; strength via layer opacity.

A workflow that works everywhere

  1. Preview first: drop the photo into the browser editor and sweep the filmstrip to check the direction — rendered on your device, nothing uploaded.
  2. Then download: a single .cube is on each look page (e.g. Kodak Portra 400), or take all 64 at once.
  3. Install using the table above, then verify: apply the LUT, switch it off again, and the image should return exactly to the original. If it does not, the slot or the colour management in front of it is wrong.
  4. Set the strength: most apps expose Intensity / Amount / opacity. Judge at 100 % first, then dial back. A LUT is a colour mapping — it cannot recover clipped white.

Three traps worth knowing

  • Resolve cannot see the LUT: after copying the file, press Update Lists / Refresh — Resolve does not rescan the folder automatically.
  • Final Cut Pro does not show it: FCP reads the LUT folder at launch, so restart it after adding files.
  • Lightroom Classic says it cannot open .cube: true — but the LUT can be packaged as a profile (last row of the table) and then used from the Profile Browser.
