Your photos stay on your computer

This page only describes what actually happens. No legal boilerplate.

Updated 2026-11-19

Photos

Photos are decoded, developed, rendered and exported inside the browser, in a Web Worker and on the GPU. There is no upload endpoint and no code path that sends image data to a server. Close the tab and the photo is gone, unless you saved the exported JPEG yourself.

Network requests

The page only requests its own assets: HTML, scripts, fonts, the sample photo, the LUT pack, and the ~3.4 MB decoder that is fetched the first time a RAW is opened. There is one /api/geo request to Cloudflare that returns a two-letter country code, used solely to choose the initial interface language. It carries no photo data and is not written to a database.

Local storage

  • .cube LUTs you import are stored in the browser's IndexedDB, on this machine only.
  • Preferences such as interface language, Fit/Fill and the auto-brightness toggle are stored in localStorage.
  • No sign-in, no tracking cookies, no third-party analytics, no ads.

Hosting

The site runs on Cloudflare Workers. As with any website, the host processes request metadata (IP address, User-Agent, timestamp) for delivery and security. The project does not build user profiles or use that data for analytics or marketing.

Changes

If this policy changes materially, the change lands with the code and is visible in the repository history.
