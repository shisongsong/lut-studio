Where vendor LUTs come from, and how to use them

Panasonic, Fujifilm, Canon, Nikon and Sony all publish their own .cube LUTs for free — but their terms only allow personal local use and forbid redistribution, which is why they are not in this site’s repository. Here are the official entry points, the log input each pack expects, and how to import one locally.

Updated 2026-11-255 min read

The 64 looks that ship with the editor are original recipes under the MIT licence and can be downloaded as a pack. Vendor LUTs are a different thing: they are conversion tables built for that camera’s own log curve. Applied correctly they get very close to the manufacturer’s look; applied straight to an sRGB photo they blow out and shift colour — not because the LUT is broken, but because its input precondition is not met.

Some pages redirect by region or ask for an account; Nikon ships its LUTs as a Windows / macOS installer that unpacks .cube files into a 3DLUT folder. Vendors change these URLs every few years — if one is dead, open an issue and this page gets updated.

Three steps to import

  1. Download the .cube from the official page above (some are zips — unzip first).
  2. Open the editor and import: in the browser editor, press “Import LUT” at the bottom and choose the file. It is parsed locally, stored in the browser’s IndexedDB and appears under “My LUTs”; it survives a reload.
  3. Confirm the input curve: files whose name carries F-Log / F-Log2 / V-Log switch automatically; for older files whose name says nothing, open the “Input curve” panel (the sRGB button at the bottom) and pick it manually.

Why the input curve matters

Log encoding flattens scene brightness: shadows are lifted so the 0–1 code range carries far more dynamic range than a display does. A vendor conversion LUT is authored for input that is already log-encoded — every code value corresponds to a known scene luminance. An ordinary photo is display-encoded sRGB, where the same shadow detail sits at a much higher code value. Feeding sRGB to a log LUT tells it “this shadow is far darker than it is”, so the image goes dark and the colour drifts. The input curve re-encodes the photo with the matching log transfer function before the table is sampled.

Gamut is still treated as sRGB, so vendor LUTs land close to, but not byte-exact, the manufacturer’s output. The input curve only decides what the LUT receives — it is not a grade by itself. With no log LUT converting back to display, a washed-out picture is expected.

The limits

  • Vendor terms cover personal local use only: never redistribute the files with a plugin, preset pack or site. Always point at the manufacturer’s page.
  • These LUTs are made for log video. Judging one on a photo, start at 100 % strength but expect 30–60 % to look more natural.
  • A LUT is a colour mapping: fully clipped highlights cannot come back, and RAW highlight recovery happens before the LUT — which is why this editor develops the RAW in 16-bit linear, applies the display transform, then samples the table.
  • To fix two LUTs into one file, stack and merge them into a single .cube in the editor and download that.
