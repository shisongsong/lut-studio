获取 LUT

LUT Archive 自带 64 个自研 look，全部由 scripts/looks.mjs 的调色配方生成， MIT 授权，可以直接下载成 .cube 用在 Resolve / Premiere / Photoshop 里。 不清楚 LUT 的 1D / 3D 区别和 LOG 输入前提，先看 LUT 是什么； 想看这 64 个 look 的具体风格，LUT 目录 里有全部名称和适用场景。

厂商官方 LUT（松下、富士、佳能、尼康、索尼）是免费下载的，但条款只允许本机个人使用， 不能再分发。所以它们不在仓库里，而是由你自己下载后导入——整个过程只在本机完成。

最后更新：2026-11-17 · 导入功能 v1

三步导入

  1. 从下面的官方页面下载 .cube 文件（有些是 zip，解压后使用）。
  2. 打开 LUT Archive，点底部「导入 LUT」。
  3. 选择文件即可。LUT 会存进浏览器 IndexedDB，出现在「我的 LUT」分类里，刷新不丢。
官方 LUT 大多是为 LOG 素材（V-Log / F-Log）做的转换，直接套普通 sRGB 照片会过曝、偏色。 导入后应用会自动把「输入色彩空间」切到对应的 LOG（F-Log / F-Log2 / V-Log）， 先把照片按该 log 曲线重编码再套 LUT——这样官方 LUT 才会按设计的样子出图。 色域仍按 sRGB 处理，所以色相会有轻微偏差，不是逐字节一致。 底部那一排的 sRGB / F-Log / F-Log2 / V-Log 按钮可以手动切换。 想在别的软件里复现同一套观感，可以先在 编辑器 里把两层 look 合并成一个 .cube 再下载。
RAW（NEF / CR2 / CR3 / ARW / DNG / RAF 等）可以直接上传，而且是真冲洗：应用内置了 flashraw 的 WebAssembly 版本（约 3.4 MB，第一次上传 RAW 时才下载），在本机完成解包、 AHD 去马赛克、相机白平衡、相机色彩矩阵和 sRGB 编码。26MP 的尼康 NEF 约 1 秒出全分辨率 5568×3712，导出也是 100% 原始尺寸。尼康的 HE/HE*（TicoRAW）压缩也支持——这是很多开源 RAW 软件还读不了的格式。文件完全解不开时才会退回内嵌的相机 JPEG。

为什么仓库里不放这些 LUT

松下、富士等厂商的 LUT 下载页只写了「免费下载」，没有开源或再分发许可；按站点条款， 它们仅限本机个人使用。把这些文件放进公开仓库属于再分发，会让仓库面临下架风险。

所以 LUT Archive 的做法是：内置的 64 个 look 全部自研、MIT 可分发；第三方 LUT 由用户自己下载后本地导入。 功能上两者完全一样——都能当 A/B 轨用，都能调强度。

下载内置的 64 个 LUT

仓库里的 luts-src/ 就是全部 64 个 33³ .cube 文件，文件名即 look id。 也可以本地重新生成：

  1. npm run export:cubes — 从调色配方生成 .cube
  2. npm run build:luts — 烘焙成网站用的 public/luts.bin
