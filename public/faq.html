使用之前，你大概会问的 12 个问题

照片去了哪里、能打开哪些文件、LUT 有多精确、断网还能不能用——这一页按实际实现回答，也把做不到的部分一起说清楚。

更新 2026-11-196 分钟

这一页把使用前最常被问到的 12 个问题一次答完：照片会不会上传、能打开哪些 RAW、LUT 用多大尺寸、能不能离线、导出得到什么、手机上能不能用。答案按实际实现写，包括它做不到的部分。

想先看它怎么工作，读在浏览器里打开 RAW；想比较桌面软件，看与 Lightroom 的对比。

问题与答案

照片会被上传到服务器吗？

不会。RAW 解码在本机的 Web Worker 里完成，显影和渲染在 GPU 上完成，文件只在本机读取，没有上传接口。整站只有两类网络请求：应用自身的静态资源，以及用来选择初始界面语言的 /api/geo 国家码查询。没有账号系统，也没有统计或跟踪 Cookie，细节写在隐私说明里。

支持哪些 RAW 格式？

NEF / NRW（含 HE、HE* 压缩）、CR2、CR3、ARW、SRF、SR2、DNG、RAF、ORF、RW2、PEF、SRW、3FR、ERF、KDC、MOS、IIQ、X3F。普通的 JPEG、PNG、WebP、AVIF、HEIC/HEIF、TIFF 也能打开。如果某个 RAW 完全拆不开，会退回到文件里内嵌的相机 JPEG，而不是显示半张黑图。

真的免费吗？用什么许可证？

免费，也不需要注册。代码以 MIT 许可证开源，源码在 GitHub 上，可以自己读、自己部署。没有订阅，也没有需要付费才能解锁的功能。

LUT 是什么？内置 LUT 用多大尺寸？

LUT 是一张“输入颜色对应输出颜色”的查找表，等于把一条调色固化下来，套用时比重新调一遍滑块更快，也更容易带到别的软件里。内置的 64 款 look 打包成 33×33×33：每个通道 33 级，共 35,937 个节点，相对原始配方是精确的。我们也测过更小的尺寸——17³ 平均误差 0.226 级（满量程 255，最大 20.8），21³ 平均 0.182（最大 11.6），25³ 平均 0.128（最大 11.3）；再往上到 65³ 只是把体积放大几十倍，看不出差别。全部 look 在 LUT 目录里。

可以导入自己的 .cube 文件吗？

可以。3D LUT（LUT_3D_SIZE 2–128）和 1D LUT 都支持，1D 会烘焙到 3D 网格上，带 UTF-8 BOM 的文件也能正常读。文件在本机解析，不经过服务器；导入后出现在“我的 LUT”里，关掉页面再打开还在。

双 LUT 和合并功能是干什么用的？

两个槽位可以各放一款 look、各自调强度，比如一层偏冷的胶片底子加一层很轻的高光暖色。调好之后，合并会按渲染时的规则 mix(v, lut(v), strength)（每个槽位各算一次）把两层烘焙成一个 33³ LUT，存进“我的 LUT”，并下载成 .cube（35,937 行）；拿到 Premiere、Resolve 或其他支持 .cube 的软件里，看到的就是同一套颜色。

为什么厂商 LUT 需要 F-Log / V-Log？

富士、松下等厂商发布的 LUT 是按 log 编码的画面做的：输入不是普通显示图，而是把高光压进码值范围的 log 信号，直接套在 sRGB 画面上颜色会偏。这个工具提供 sRGB / F-Log / F-Log2 / V-Log 输入配置：选对应项后，画面先用厂商公布的传递函数重新编码，再让 LUT 运行；名字里带 F-Log 或 V-Log 的 LUT 会自动识别。色域仍按 sRGB 处理，所以结果接近，但不是逐字节复刻。原理见浏览器 RAW 指南。

导出得到什么？

JPEG，按源图长边的 50 / 75 / 100% 三档输出，质量分别是 0.90 / 0.95 / 0.98。选 100% 时，用内存里的全分辨率帧分块渲染，可以超过 GPU 纹理上限，不会偷偷缩图。导出的是已经应用了显影和 LUT 的成品；没有 TIFF 或 DNG 输出。

手机上能用吗？

能。编辑器有窄屏布局，在支持 WebGL2 的手机浏览器里可以运行；如果设备或浏览器不支持 WebGL2，编辑器渲染不了。手机上用不到键盘快捷键，切换 look、导出都在界面按钮上。界面语言按国家自动选择，也可以在工具栏切换中英文。

能离线用吗？

没有“离线模式”开关，实际能不能用取决于浏览器缓存。第一次访问要联网加载应用资源，第一次打开 RAW 还要下载约 3.4 MB 的解码器；这些资源被浏览器缓存下来之后，断网再打开同一台机器上的页面通常还能继续用，前提是缓存没有被清掉。清空缓存、换浏览器或换设备之后，需要重新联网下载一次。

有图库或者批量模式吗？

没有。这是一个单张编辑器：一次处理一张照片，没有目录、评分、关键字、批量队列，也没有云同步。要做批量或长期图库，桌面软件更合适，与 Lightroom 的对比里写了它在哪里停下来。

导入的 LUT 存在哪里？

存在浏览器的 IndexedDB 里，归在“我的 LUT”名下；合并出来的 LUT 也存在同一处，界面偏好则放在 localStorage。它们不会上传，也不会在设备之间同步。清空站点数据会一起清掉，所以想保留合并好的 look，记得下载成 .cube 存到本地。
